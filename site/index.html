Why igdl

⬇

One click, one file

Paste a link or grab it straight off your clipboard — igdl merges video and audio into a single mp4 in your Downloads folder.

▶

Actually plays back

Instagram sometimes only serves VP9 video, which QuickTime and Photos can't open. igdl auto-transcodes to H.264 so it always plays.

⚙

Built on yt-dlp + ffmpeg

No custom scraping to break — igdl is a thin, well-tested layer over the tools already trusted for this job.

🔒

No telemetry, ever

Downloads only the URL you give it. Nothing is uploaded, logged, or phoned home — it's all local.

Install

Two parts: the menubar app (this download), and the igdl CLI it drives.

1

Download & open the DMG

Drag IGDL.app to your Applications folder.

2

First launch: right-click → Open

The app is ad-hoc signed but not notarized, so Gatekeeper will warn once — right-click the app and choose Open to bypass that (only needed the first time).

3

Set up the CLI it depends on

Clone the repo, run brew install ffmpeg then make setup — see the README for the full one-time setup.

4

Paste a link, click Download

Click the ↓ icon in your menubar, paste an Instagram reel or post URL, and you're done.
